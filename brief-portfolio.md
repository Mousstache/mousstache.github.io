## 4. Direction artistique

- **Ambiance :** colorée, fun, énergique — mais lisible et pro (on vend à des patrons de TPE)
- **Palette [À VALIDER] :** fond crème clair `#FFF8EE`, texte quasi noir `#1A1A2E`, accents vifs : violet `#7C3AED`, corail `#FF6B6B`, jaune `#FFD23F`, vert menthe `#2EC4B6`. Chaque offre/projet a sa couleur.
- **Typo :** titres en grosse display arrondie (ex. *Bricolage Grotesque* ou *Clash Display*), texte en *Inter* ou *DM Sans*
- **Formes :** blobs, coins très arrondis, ombres décalées « néo-brutalistes » (bordure noire + ombre pleine)
- **Animations :** apparition au scroll, hover tilt sur les cartes, curseur personnalisé, micro-interactions sur les boutons, un easter egg (ex. konami code → confettis)
- **Projets bien visibles :** grandes captures, vidéos courtes en boucle
- **Perf :** animations désactivées si `prefers-reduced-motion`, site rapide sur mobile (Lighthouse 90+)

---

## 5. Technique

- **Framework :** Next.js (App Router) + React + TypeScript
- **Style :** Tailwind CSS
- **Animations :** Framer Motion
- **Blog :** fichiers MDX dans le repo
- **Formulaire :** service externe (Web3Forms ou Formspree) — pas besoin de serveur
- **Hébergement [À VALIDER] :**
  - Option 1 — **GitHub Pages** (`github.io`) : gratuit, mais nécessite l'export statique de Next.js (`output: 'export'`) et **Express ne peut pas tourner dessus** (hébergement statique uniquement).
  - Option 2 (recommandée) — **Vercel + nom de domaine perso** (~10 €/an, ex. `moussatroiano.fr`) : plus crédible sur un profil Malt, déploiement auto depuis GitHub, et le repo reste public comme preuve.
- **SEO :** métadonnées, Open Graph (belle carte quand le lien est partagé sur WhatsApp/Malt), sitemap
- **Langue :** français uniquement
